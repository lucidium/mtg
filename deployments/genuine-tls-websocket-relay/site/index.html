Get started

Three commands. No account required to pull public images.

  1. Point Docker at the registry. The registry speaks the standard OCI distribution protocol, so no special client is needed.
    $ docker login registry.liandry.org
  2. Pull an image.
    $ docker pull registry.liandry.org/library/runtime:3.21
  3. Run it.
    $ docker run --rm -p 8000:8000 registry.liandry.org/library/app:3.21

Prefer a different client? podman, buildah, crane, and skopeo all work the same way — point them at registry.liandry.org.

Why Liandry

OCI-compatible

Implements the Open Container Initiative distribution specification, so any conforming client works out of the box.

Small, reproducible layers

Images are built reproducibly from version-pinned sources and published with attested build metadata.

Fast global pulls

Layered storage with on-disk deduplication keeps pulls quick and bandwidth low, even on constrained links.

Clear versioning

Immutable tags per release plus a moving latest tag. Digests are always available for pinning.

Signed images

Releases are cryptographically signed; verify an image against the published public key before you run it.

No vendor lock-in

Standard protocols, standard formats. Move images in and out freely with the tools you already use.

Frequently asked questions

Is Liandry free to use?

Yes. Pulling public images is free and does not require an account. Hosting your own images under a personal namespace is also free within reasonable per-user storage limits.

Which image types are supported?

Any OCI image and Docker image manifest, including OCI image indexes (multi-architecture images). Schema v2 manifests are supported; the legacy v1 format is not.

How do I verify an image?

Every release publishes a SHA-256 digest alongside its tag. Pull by digest (docker pull registry.liandry.org/library/app@sha256:…) to guarantee you get exactly the bytes that were published.

Are images available for multiple architectures?

Yes. The base, runtime, and application images are published as multi-architecture indexes covering amd64 and arm64. Your client automatically selects the right variant.

How are images built?

All images are built in a clean, reproducible environment from public source. Build metadata and the list of installed packages are attached to each release.

About
